Set up your admin PIN.

The admin username is headadmin. Choose a new 6–12 digit PIN that is not used for your church register or any other account.

  1. Open your Pexoluma Supabase project.
  2. Open SQL Editor and start a new query.
  3. Paste the SQL below and replace the placeholder with your own PIN. Do not send the PIN to anyone.
  4. Run it once, then remove the PIN from the saved SQL query/history if the dashboard offers that option.
  5. Return to Admin Dashboard and sign in as headadmin.
insert into public.pex_admin_credentials (id, username, pin_salt, pin_hash)
values (
  true,
  'headadmin',
  'bcrypt',
  extensions.crypt('REPLACE_WITH_YOUR_PRIVATE_6_TO_12_DIGIT_PIN', extensions.gen_salt('bf', 12))
)
on conflict (id) do update
set username = excluded.username,
    pin_salt = excluded.pin_salt,
    pin_hash = excluded.pin_hash;

Only the one-way bcrypt hash is stored in the database. The SQL editor query may temporarily contain your chosen PIN, so do not share the query or a screenshot of it.
